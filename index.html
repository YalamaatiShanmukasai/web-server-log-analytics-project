Web Server Log Analytics using Hadoop, Hive and Pig

Project Details

This project performs web server log analytics using the Hadoop ecosystem, mainly HDFS, Apache Hive, and Apache Pig. The analysis identifies request patterns, HTTP methods, response statuses, frequently accessed pages, server errors, response times, and client activity.

Technologies Used

  • Apache Hadoop / HDFS
  • Apache Hive
  • Apache Pig
  • HiveQL
  • Pig Latin
  • MapReduce
  • CSV
  • GitHub

Dataset Summary

The project dataset contains 10 records.

  • Total records: 10
  • GET requests: 7
  • POST requests: 3
  • HTTP statuses: 200, 302, 404, 500
  • 404 errors: 1
  • 500 errors: 1
  • Pages: /checkout, /cart, /home, /login, /products, /payment

2. Apache Pig

Apache Pig is used to process and analyze the web server logs.

Load Dataset

       AS (ip:chararray,

3. Apache Hive

Hive is used to query the web server logs using HiveQL.

Create Database

CREATE DATABASE IF NOT EXISTS web_log_analytics;
USE web_log_analytics;

Create Table

CREATE TABLE web_logs_raw (
   ip STRING,
   timestamp STRING,
   method STRING,
   page STRING,
   status INT,
   response_time_ms INT,
   user_agent STRING
)
ROW FORMAT DELIMITED
FIELDS TERMINATED BY ','
STORED AS TEXTFILE;

Project Summary

This project demonstrates a Hadoop-based web server log analytics workflow using HDFS, Apache Pig and Apache Hive. The system processes web server logs to study website traffic, user navigation, HTTP methods, response statuses, errors, response times and frequently accessed pages.

The project includes data storage in HDFS, cleansing and transformation using Pig Latin, analytical queries using HiveQL, and performance optimization concepts such as partitioning and bucketing.
